
# Employee Payroll System

A Java Swing desktop application for managing employee records and calculating salaries.

## Features
- Add employee details
- Select employee department
- Calculate allowances and deductions
- Calculate net salary
- Save employee records to a text file
- Load saved employee records
- View all employee salary details
- Prevent duplicate employee IDs

## Technologies Used
- Java
- Java Swing
- AWT
- ArrayList
- File Handling
- Exception Handling

## Salary Calculation
- Allowance = 20% of Basic Salary
- Deduction = 10% of Basic Salary
- Net Salary = Basic Salary + Allowance - Deduction

## How to Run
1. Install the Java JDK.
2. Download `ep.java`.
3. Open Command Prompt in the folder containing the file.
4. Compile the program:

   javac ep.java

5. Run the program:

   java ep

## Storage
Employee records are saved in:

C:\javapractice\employees.txt
